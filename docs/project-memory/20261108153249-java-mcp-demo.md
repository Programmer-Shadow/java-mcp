# Java MCP 入门示例

## 目标与约束
- 用户是 Java 开发者，需要最简单的可运行项目，理解传参、接收、处理和返回，允许以后逐步加入 Spring AI、LangChain。
- 本阶段采用官方 Java SDK 2.0.1、Java 17+、Maven；单项目两个 main，STDIO 子进程通信。技术选择为实现者选择。
- 只演示 add(a,b)，不连接大模型、数据库、网络服务，不需要凭据，不实现生产部署。

## 架构、数据与接口
- DemoClient 初始化 MCP 连接，发现工具，用 CallToolRequest 传递 Map 参数，读取 CallToolResult。
- DemoServer 注册 add 工具及 JSON Schema；收到 request.arguments() 后验证数字并相加，返回文本内容。
- 客户端自动启动同一可执行 jar 的 server 模式，SDK 承担 JSON-RPC 编解码、握手和进程流传输。
- 数据流：Map → JSON-RPC tools/call → arguments Map → 业务计算 → content 文本 → 客户端。
- 不持久化数据；内存状态随进程退出释放。

## 安全、异常与恢复
- 无秘密值，无外部端口；服务端 stdout 专供协议使用，业务日志写 stderr。
- Schema 和处理器校验参数；工具错误通过 isError 返回，连接错误由客户端报告；不自动重试。
- 关闭客户端释放服务端进程；重启客户端即可恢复；源文件由 Git 管理，不自动提交，不需数据备份。
